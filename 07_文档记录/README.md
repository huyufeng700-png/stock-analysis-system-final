# 小胡瓜量化平台 - 目录结构 v1.0

## 📁 目录说明

| 目录 | 功能 | 包含文件 |
|---|---|---|
| `01_策略引擎/` | 核心交易策略规则 | 九条经验规则.py、五层确认框架.py |
| `02_选股系统/` | 选股逻辑与日报生成 | 蜘蛛网4.3_量化选股.py、小胡瓜_选股workflow.py、daily_trading_strategy.py、daily_run_v3.py |
| `03_持仓管理/` | 持仓监控与风控 | 小胡瓜_持仓管理.py |
| `04_数据采集/` | 舆情与数据源抓取 | news_sentiment_monitor.py |
| `05_工具脚本/` | 辅助工具与启动脚本 | run_codegraph_mcp.sh |
| `archive/` | 历史版本与归档文件 | - |
| `研究档案/` | 策略研究与回测记录 | - |
