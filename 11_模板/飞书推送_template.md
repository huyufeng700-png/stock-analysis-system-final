# 飞书推送模板

## 卡片结构
- 标题:`[cron 名] 日期 时间`
- 状态:`✅ 正常 / ⚠️ 异常 / ❌ 失败`
- 数据表(3-5 行)
- 一句话结论
- 详情链接(本地路径)

## 9am 量化日报(发到 Home)
```
🕐 2026-07-31 09:00 量化日报
策略路由:🟢 主升 / 🟡 震荡 / 🔴 退潮
今日持仓动作:N(列代码)
今日选股:M 只(列代码 + 评分)
明日计划:1 句话
```

## 18h 持仓总结(发到 Home)
```
🕐 2026-07-31 18:00 持仓总结
今日盈亏:±X.XX%
持仓:N 只
  涨停:Z 只(列)
  跌停:W 只(列)
  触发止损:V 只(列)
明日预案:1 段
```

## 15h 蜘蛛网选股(发到 Home)
```
🕐 2026-07-31 15:00 蜘蛛网 v4.3 选股
评分 ≥ 8:N 只
评分 6-8:M 只
评分 < 6:K 只(备选)
```

## On-call 健康度告警(发到 On-call 群)
```
🔴 [P0] 2026-07-31 14:30 cron 故障
job_id:xxx
job_name:xxx
连续失败:N 次
原因:1 句话
动作:已 pause / 已恢复
```

## 通用硬规则
- ❌ 标题不带 emoji 装饰(别用 💎🔥🚀)
- ✅ 标题用 `[cron 名] + 日期 + 时间`
- ❌ 不推个股代码推荐(只推状态判断+候选清单)
- ❌ 不推"买入"建议(老胡瓜 07-13 边界)
