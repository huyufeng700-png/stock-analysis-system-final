# 五层确认(人话版)

> 源自 `01_策略引擎/五层确认框架.py` — A 股量化选股"入场前最后关卡"
> 2026-07-31 沉淀

## 🏯 五层金字塔

### Layer 1: 可交易性过滤
**白话**:**这票能不能买**?
- 流动性:成交额 > 1 亿(太小没空间)
- 波动性:日内振幅 > 2%(没波动 = 没机会)
- 风险排除:不是涨跌停(追高/接刀风险大)

**打分**:0 或 1,通过/不通过

### Layer 2: 趋势 + 结构确认
**白话**:**走势对不对**?
- 价格位置:在 20 日均线上方?在近期高点附近?
- 均线多头:MA5 > MA10 > MA20
- 突破结构:突破近期震荡区间?
- 收 K 位置:接近日内高点(+),接近日内低点(-)

**打分**:0-100

### Layer 3: 市场环境判断
**白话**:**大盘/板块是啥状态**?
- **趋势市场**:用趋势指标(MA / MACD)
- **震荡市场**:用摆动指标(RSI / KD)
- **不同市场用不同指标**——硬上 = 错

**打分**:0-100

### Layer 4: 硬确认 + 软确认
**白话**:**盘面 + 外部共振**?
- **硬确认**(盘面):成交量突破、龙头跟进
- **软确认**(外部):舆情/政策/产业链

**打分**:0-100,**共振数越多越好**

### Layer 5: 综合评分
**白话**:**最终决策**。
- 5 个维度加权:质量 / 时机 / 资金流 / 执行风险 / 共振数
- 总分 0-100
- **阈值**:
  - ≥ 80:BUY(强买入信号)
  - 60-79:HOLD(可持有/关注)
  - < 60:SELL(不碰)

## 🎯 跟九条经验的关系

| 维度 | 九条经验 | 五层确认 |
|---|---|---|
| **作用** | 选什么(横向筛选) | 入场决策(纵向把关) |
| **粒度** | 9 条独立规则,可加权 | 5 层串行,前 1 层不过就拒 |
| **输出** | 综合评分 0-100 | BUY / HOLD / SELL 信号 |
| **数据源** | 行情 + K 线 | 同 + 舆情 + 板块 |

**协作方式**:
1. 九条经验**筛出候选**(从全市场 → 候选池)
2. 五层确认**过 5 关**(从候选池 → 最终 BUY 列表)

## 🛡️ 风控边界

- Layer 1 不通过 = 直接不碰,不进后 4 层
- Layer 5 < 60 = SELL,跟九条经验 8.0 阈值对齐
- **绝不逆 Layer 1 操作**(流动性差 = 风险)
