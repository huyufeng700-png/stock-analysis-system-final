## 🎯 通用模式(给后续决策做参考)

### "测试"信号
- 触发:用户说"测试""来看看"等模糊词
- 反应:1 句总结 + 3 选项 + 等,不抢答
- 反模式:答非所问 + 主动提方案

### "继续/再推"+"测试"+"收工"+"执行下一步"+"复盘" 5 姿态
| 姿态 | 默认反应 |
|---|---|
| "继续" + 明确动词 | 默认推进 + 一次性末报 |
| "测试" | 信任测试,1 句总结 + 3 选项 + 等 |
| "收工" | 1 段总成绩 + 1 句明天 hook + 不反问 |
| "执行下一步" | 默认按建议清单第 1 项直做 + 末报 |
| "复盘" | 反思沉淀 ≥5 段(流程视角/产出盘点/认知链/反模式/明日 hook 重述) |

### 决策三问
1. 外部 API 依赖?
2. 要升什么/有什么用?
3. 升级类必 1 句"依赖清单"+"说人话价值"+拍板选项

### 承载性假设边界
- 写 v0.X 草稿 / 改 OpenClaw / 重启 gateway 必 ask 1 句
- "继续"+"做"+明确动词 = 授权直做
