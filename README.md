# 股票分析系统

本仓库为股票分析系统的源码和配置，运行时数据（持仓、选股、回测、舆情等）均存放在 `runtime/` 目录，已通过 `.gitignore` 排除。

## 结构
- `01_策略引擎/`：策略、研究档案等
- `02_选股系统/`：蜘蛛网选股、工作流
- `03_持仓管理/`：持仓相关
- `04_数据采集/`：舆情监控
- `06_cron任务/`：各种定时任务
- `scripts/`：通用工具（如 fallback_pool）
- `tests/`：单元测试
- `10_配置/`：配置文件（如 paths.yaml）

> 运行前请确保已安装依赖（如 requests、feedparser、akshare 等），并根据实际环境修改配置。
